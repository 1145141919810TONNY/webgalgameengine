# 立绘指令使用指南

本指南详细说明了 Shiori 引擎中立绘（Character）控制的指令格式。通过在 `story` 数组的 `chars` 字段中使用特定的语法，您可以精确控制角色的位置、层级、大小和动画效果。

## 1. 基本语法结构

立绘指令采用方括号包裹的形式：`[修饰词 角色ID]`。

- **修饰词**：用于定义立绘的属性（如位置、缩放等），多个修饰词之间用空格分隔。
- **角色ID**：在配置文件中定义的立绘标识符（如 `lh01`, `lh02`）。
- **多立绘控制**：如果需要同时控制多个立绘，可以使用逗号分隔多个指令，例如：`"[左 lh01],[右 lh02]"`。

**示例：**
```javascript
chars: "[中 lh01]" // 显示 ID 为 lh01 的立绘，位置居中
```

## 2. 中英文别名支持

### 2.1 关键词映射表

#### 水平位置

| 中文 | 英文别名 | 屏幕百分比 (Left) | 说明 |
| :--- | :--- | :--- | :--- |
| `左左` | `leftl` | 15% | 最左侧 |
| `左` | `left` | 25% | 偏左侧 |
| `左右` | `leftr` | 35% | 微偏左 |
| `中` | `middle` / `center` | 50% | 屏幕正中央（默认值） |
| `右左` | `rightl` | 65% | 微偏右 |
| `右` | `right` | 75% | 偏右侧 |
| `右右` | `rightr` | 85% | 最右侧 |

#### 垂直位置

| 中文 | 英文别名 | 偏移量 (Bottom) | 说明 |
| :--- | :--- | :--- | :--- |
| `下` | `down` | -25% | 向下轻微偏移 |
| `中下` | `downm` | -50% | 向下中等偏移 |
| `下下` | `downd` / `bottom` | -65% | 向下大幅偏移 |
| `上` | `up` | 25% | 向上轻微偏移 |
| `中上` | `upm` | 50% | 向上中等偏移 |
| `上上` | `upu` / `top` | 65% | 向上大幅偏移 |

*注：不指定垂直关键词时，默认为 `0`（底部对齐）。*

#### 层级控制

| 中文 | 英文别名 | zIndex 值 | 说明 |
| :--- | :--- | :--- | :--- |
| `前` | `front` | 11 | 顶层（覆盖在其他立绘之上） |
| `后` | `back` | 9 | 底层（被其他立绘遮挡） |

*注：基础层级为 10。*

#### 动画控制

| 中文 | 英文别名 | 效果 |
| :--- | :--- | :--- |
| `瞬` | `moment` / `instant` | **瞬移**：禁用过渡动画，立绘立即切换到目标状态 |

#### 消失指令

| 中文 | 英文别名 | 效果 |
| :--- | :--- | :--- |
| `消失` | `hide` / `remove` | 移除指定立绘或全部立绘（见第10节） |

#### 动作指令

动作指令用于对立绘应用特殊的动画效果。当使用动作指令时，**瞬移指令（`瞬`/`instant`）会被自动忽略**，以确保动画正常播放。

| 中文 | 英文别名 | 效果说明 |
| :--- | :--- | :--- |
| `后退` | `back` | Y轴向上+10%，缩放-10%，层级强制变为"后"（zIndex=9） |
| `前进` | `forward` | Y轴向下-10%，缩放+10%（上限2.0），层级强制变为"前"（zIndex=11） |
| `吓一跳` | `scare` | 先放大7%再缩小7%，重复2次，总时长约1秒 |
| `发抖` | `shake` | X轴左右偏移±2%，重复3次，总时长约480ms |
| `持续发抖` | `cshake` | 持续左右抖动，需手动停止 |
| `结束发抖` | `sshake` | 停止持续发抖，恢复原位 |

### 2.2 使用示例

#### 纯中文指令（原有方式，完全兼容）
```javascript
chars: "[左 lh01]"
chars: "[中 前 10% lh02]"
chars: "[瞬 右 下 lh03]"
chars: "[消失 lh01]"
```

#### 纯英文指令
```javascript
chars: "[left lh01]"
chars: "[middle front 10% lh02]"
chars: "[instant right down lh03]"
chars: "[hide lh01]"
```

#### 中英文混合指令
```javascript
chars: "[中 front lh01]"           // 中文位置 + 英文层级
chars: "[left 下 lh02]"            // 英文位置 + 中文垂直
chars: "[right front 10% lh03]"    // 英文位置 + 英文层级 + 缩放
chars: "[瞬 middle down lh04]"     // 中文动画 + 英文位置 + 英文垂直
chars: "[remove lh01]"             // 英文消失指令
```

#### 动作指令示例
```javascript
// 后退效果
chars: "[中 back lh01]"            // Y轴向上+10%，缩小10%，层级变后
chars: "[中 后退 lh01]"            // 中文等价

// 前进效果
chars: "[中 forward lh01]"         // Y轴向下-10%，放大10%，层级变前
chars: "[中 前进 lh01]"            // 中文等价

// 吓一跳
chars: "[中 scare lh01]"           // 放大7%再缩小7%，重复2次
chars: "[中 吓一跳 lh01]"          // 中文等价

// 发抖
chars: "[中 shake lh01]"           // 左右抖动3次
chars: "[中 发抖 lh01]"            // 中文等价

// 持续发抖与停止
chars: "[中 cshake lh01]"          // 开始持续发抖
chars: "[sshake lh01]"             // 停止发抖
chars: "[中 持续发抖 lh01]"        // 中文开始
chars: "[结束发抖 lh01]"           // 中文停止
```

### 2.3 互斥处理规则

对于**同一类型**的属性（如水平位置、垂直位置、层级），如果在指令中出现了多个同类型关键词（无论是中文还是英文），**默认执行第一个出现的关键词**，忽略后续的同类关键词。

**示例：**
```javascript
// 只取第一个水平位置 “左”，忽略后面的 “right”
chars: "[左 right lh01]"  // 结果：left = 25%

// 只取第一个层级 “前”，忽略后面的 “back”
chars: "[前 back lh01]"   // 结果：zIndex = 11

// 只取第一个垂直位置 “下”，忽略后面的 “downm”
chars: "[下 downm lh01]"  // 结果：bottom = -25%

// 复杂冲突：每类取第一个
chars: "[left right 下 downm front back 10% lh01]"
// 结果：left=25%(取left), bottom=-25%(取下), zIndex=11(取front), scale=110%
```

**注意**：不同类型的关键词**不冲突**，可以同时生效。
```javascript
chars: "[左 下 前 lh01]"  // 全部生效：left=25%, bottom=-25%, zIndex=11
```

#### 动作指令的优先级规则

1. **动作指令屏蔽瞬移**：当使用动作指令时，`瞬`/`instant` 会被自动忽略，确保动画正常播放。
   ```javascript
   chars: "[瞬 back lh01]"     // '瞬'被忽略，后退动画正常播放
   chars: "[instant scare lh01]" // 'instant'被忽略，吓一跳动画正常播放
   ```

2. **多动作取第一个**：如果同时指定多个动作指令，只执行第一个，忽略后续的动作。
   ```javascript
   chars: "[后退 吓一跳 lh01]"  // 只执行'后退'，忽略'吓一跳'
   chars: "[forward scare lh01]" // 只执行'forward'，忽略'scare'
   chars: "[shake cshake lh01]"  // 只执行'shake'，忽略'cshake'
   ```

3. **动作与其他修饰词组合**：动作指令可以与位置、缩放、层级等修饰词组合使用。
   ```javascript
   chars: "[左 back lh01]"          // 左侧位置 + 后退效果
   chars: "[中 10% forward lh01]"   // 基准缩放110%，前进后变为120%
   chars: "[x:10% y:5% shake lh01]" // 精确坐标 + 发抖效果
   ```

## 3. 精确坐标控制

### 3.1 坐标系定义

#### X轴（水平位置）
- **基准点**：屏幕中心为 `0%`
- **方向**：
  - 负值（如 `-10%`）表示向左平移
  - 正值（如 `10%`）表示向右平移
- **计算方式**：`left = calc(50% + x%)`

#### Y轴（垂直位置）
- **基准点**：屏幕下边缘为 `0%`（立绘底部对齐屏幕底部）
- **方向**：
  - 正值（如 `10%`）表示向上移动
  - 负值（如 `-10%`）表示向下移动（超出屏幕底部）
- **计算方式**：`bottom = y%`

### 3.2 指令语法

使用 `x:` 和 `y:` 前缀来指定精确百分比坐标。

**基本格式：**
```javascript
[x:水平偏移 y:垂直偏移 角色ID]
```

**示例：**
```javascript
// 向右平移10%，向下移动5%
chars: "[x:10% y:-5% lh01]"

// 向左平移20%，向上移动15%
chars: "[x:-20% y:15% lh02]"

// 仅指定X轴，Y轴使用默认值
chars: "[x:30% lh01]"

// 仅指定Y轴，X轴使用默认值（居中）
chars: "[y:10% lh01]"

// 结合其他修饰词使用
chars: "[x:15% y:-10% front 10% lh01]"  // 精确坐标 + 层级 + 缩放
chars: "[瞬 x:-25% y:20% lh01]"         // 瞬移 + 精确坐标
```

### 3.3 优先级规则

**精确坐标指令具有最高优先级**：

- 如果检测到 `x:` 参数，则**忽略所有水平位置相关的文字关键词**（`左左`, `左`, `左右`, `中`, `右左`, `右`, `右右` 及其英文别名）
- 如果检测到 `y:` 参数，则**忽略所有垂直位置相关的文字关键词**（`下`, `中下`, `下下`, `上`, `中上`, `上上` 及其英文别名）
- 如果未提供 `x:` 或 `y:`，则回退到原有的文字关键词解析逻辑

**示例：**
```javascript
// x: 优先于文字指令
chars: "[x:10% 左 lh01]"  // 结果：使用 x:10%，忽略“左”

// y: 优先于文字指令
chars: "[y:15% 下 lh01]"  // 结果：使用 y:15%，忽略“下”

// 精确坐标与文字指令混合（精确坐标生效）
chars: "[x:-20% 中 y:10% 下 lh01]"
// 结果：x=-20%（忽略“中”），y=10%（忽略“下”）

// 仅部分使用精确坐标
chars: "[x:10% 下 lh01]"
// 结果：x=10%（精确），y=-25%（使用“下”）
```

### 3.4 实际应用场景

#### 场景1：微调立绘位置
```javascript
// 将居中的立绘稍微向右调整
chars: "[x:5% lh01]"

// 将立绘稍微向上提升
chars: "[y:8% lh01]"
```

#### 场景2：精确定位对话角色
```javascript
// 角色站在屏幕左侧偏中的位置
chars: "[x:-15% lh01]"

// 角色站在屏幕右侧偏中的位置
chars: "[x:15% lh02]"
```

#### 场景3：特殊效果（半隐藏）
```javascript
// 立绘下半部分隐藏在屏幕外
chars: "[y:-30% lh01]"

// 立绘上半部分隐藏在屏幕外
chars: "[y:50% lh01]"
```

#### 场景4：组合使用
```javascript
// 精确定位 + 层级 + 缩放
chars: "[x:-10% y:5% front 15% lh01]"

// 瞬移 + 精确坐标
chars: "[瞬 x:20% y:-10% lh01]"

// 中英文混合 + 精确坐标
chars: "[x:10% front instant lh01]"
```

### 3.5 注意事项

1. **百分比基于屏幕尺寸**：`x:10%` 表示屏幕宽度的10%，`y:10%` 表示屏幕高度的10%
2. **与缩放的关系**：精确坐标在缩放之前应用，缩放不会影响坐标基准点
3. **过渡动画**：精确坐标同样支持平滑过渡动画，除非使用 `[瞬]` 指令
4. **兼容性**：精确坐标功能完全向后兼容，不影响原有的文字指令

| :--- | :--- | :--- |

## 7. 缩放比例

使用带有 `%` 符号的数字来调整立绘的大小。

- **计算规则**：最终缩放比例 = 1 + (输入数值 / 100)。
- **正值**：放大。例如 `10%` 表示放大到 110%。
- **负值**：缩小。例如 `-20%` 表示缩小到 80%。
- **零值**：`0%` 表示保持 100% 原始大小。
- **默认**：不写默认为 100% 原始大小

**代码示例：**
```javascript
// 放大到 115%
chars: "[中 15% lh01]"

// 缩小到 80%
chars: "[中 -20% lh01]"
```

## 8. 动画控制

默认情况下，立绘的位置或大小变化会带有 0.5 秒的平滑过渡动画。

| 关键词 | 效果 |
| :--- | :--- |
| `瞬` | **瞬移**：禁用过渡动画，立绘立即切换到目标状态。 |

**代码示例：**
```javascript
// 瞬间移动到左侧，无动画
chars: "[瞬 左 lh01]"

// 普通移动，有 0.5s 平滑过渡
chars: "[左 lh01]"
```
若因浏览器性能问题，平滑过渡时出现卡顿，这可能是因为你移动的距离加上其他动态效果造成的。出现这种问题可使用 `[瞬]` 或 `[instant]` 指令解决。

## 9. 组合指令示例

您可以将多个修饰词组合在一个指令中。**修饰词的顺序不影响解析结果**，引擎会自动识别每个关键词。

**解析逻辑：**
1. 提取最后一个部分作为 `角色ID`。
2. 扫描剩余部分，匹配位置、层级、缩放和动画关键词。

**常见组合示例：**

```javascript
// 水平 + 垂直
chars: "[左 下 lh01]" 

// 水平 + 缩放
chars: "[中 10% lh01]"

// 三属性组合：水平 + 垂直 + 缩放
chars: "[左 下 10% lh01]"

// 四属性组合：水平 + 垂直 + 层级 + 缩放
chars: "[右 中下 前 -15% lh01]"

// 完整组合：包含瞬移
chars: "[瞬 中 下下 20% 前 lh01]"

// 中英文混合组合
chars: "[left down front 10% lh01]"
chars: "[中 front 15% lh02]"
chars: "[instant right downm -10% lh03]"

// 精确坐标组合
chars: "[x:10% y:-5% lh01]"
chars: "[x:-15% y:10% front 10% lh02]"
chars: "[瞬 x:20% y:-10% lh03]"

// 精确坐标与文字指令混合（精确坐标优先）
chars: "[x:10% 下 lh01]"  // x使用精确值，y使用“下”
chars: "[中 y:15% lh01]"  // x使用“中”，y使用精确值
```

## 10. 清除立绘

当需要隐藏某个立绘时，使用 `消失` 指令。

### 10.1 单个立绘清除

**语法：** `[消失 角色ID]`

**代码示例：**
```javascript
// 移除 lh01
chars: "[消失 lh01]"

// 使用英文指令
chars: "[hide lh01]"
chars: "[remove lh01]"

// 同时移除多个立绘
chars: "[消失 lh01],[消失 lh02]"
```

### 10.2 批量清除所有立绘

**语法：** `[消失 all]` 或 `[消失 全部]`

**效果：** 一键清除屏幕上所有活跃立绘，包括自动停止所有动画状态（如持续发抖）。

**代码示例：**
```javascript
// 中文指令
chars: "[消失 全部]"

// 英文指令 (hide)
chars: "[hide all]"

// 英文指令 (remove)
chars: "[remove all]"
```

**实际应用场景：**
```javascript
// 场景切换前清除所有立绘
{
    text: "场景结束，清除所有角色",
    chars: "[消失 全部]"
}

// 新篇章开始，确保屏幕干净
{
    text: "新的章节开始了...",
    background: "bg_new",
    chars: "[消失 all]"
}

// 紧急清场（带音效）
{
    text: "突然所有人都消失了！",
    chars: "[remove all]",
    se: "disappear"
}
```

**注意事项：**
- 会自动清理所有动画状态（如 `cshake` 持续发抖的定时器）
- 空状态时调用不会报错
- 完全兼容原有的单立绘清除功能

## 11. 动作指令详解

动作指令为立绘提供了丰富的动态效果，可以增强视觉表现力。

### 11.1 后退 (back)

**效果：**
- Y轴：向上偏移 +10%（`bottom += 10%`）
- 缩放：减小 -10%（`scale -= 0.1`）
- 层级：强制变为"后"（zIndex=9）

**示例：**
```javascript
// 基础用法
chars: "[中 back lh01]"
chars: "[中 后退 lh01]"  // 中文等价

// 与位置组合
chars: "[左 back lh01]"   // 左侧 + 后退
chars: "[right back lh01]" // 右侧 + 后退

// 与缩放组合
chars: "[中 20% back lh01]" // 基准120%，后退后变为110%

// 连续后退
chars: "[中 back lh01]"  // 第一次：Y+10%, scale-10%
chars: "[中 back lh01]"  // 第二次：Y再+10%, scale再-10%
```

### 11.2 前进 (forward)

**效果：**
- Y轴：向下偏移 -10%（`bottom -= 10%`）
- 缩放：增大 +10%（`scale += 0.1`，上限2.0）
- 层级：强制变为"前"（zIndex=11）

**示例：**
```javascript
// 基础用法
chars: "[中 forward lh01]"
chars: "[中 前进 lh01]"  // 中文等价

// 与位置组合
chars: "[右 forward lh01]"   // 右侧 + 前进
chars: "[left forward lh01]" // 左侧 + 前进

// 与缩放组合
chars: "[中 10% forward lh01]" // 基准110%，前进后变为120%

// 连续前进
chars: "[中 forward lh01]"  // 第一次：Y-10%, scale+10%
chars: "[中 forward lh01]"  // 第二次：Y再-10%, scale再+10%
```

**后退 vs 前进对比：**

| 属性 | 后退 (back) | 前进 (forward) |
|------|------------|---------------|
| Y轴 | +10% (向上) | -10% (向下) |
| 缩放 | -0.1 (缩小) | +0.1 (放大) |
| 层级 | 强制变后 (9) | 强制变前 (11) |

### 11.3 吓一跳 (scare)

**效果：**
- 先放大7%，再缩小7%
- 重复2次完整循环
- 总时长约1秒（每步100ms）

**示例：**
```javascript
chars: "[中 scare lh01]"
chars: "[中 吓一跳 lh01]"  // 中文等价

// 与位置组合
chars: "[右 scare lh01]"
chars: "[x:10% y:5% scare lh01]"  // 精确坐标 + 吓一跳
```

### 11.4 发抖 (shake)

**效果：**
- X轴左右偏移 ±2%
- 重复3次完整循环
- 总时长约480ms（每步80ms）

**示例：**
```javascript
chars: "[中 shake lh01]"
chars: "[中 发抖 lh01]"  // 中文等价

// 与位置组合
chars: "[左 shake lh01]"
chars: "[middle down shake lh01]"
```

### 11.5 持续发抖 (cshake)

**效果：**
- X轴持续左右抖动
- 需要手动调用 `sshake` 停止

**示例：**
```javascript
// 启动持续发抖
chars: "[中 cshake lh01]"
chars: "[中 持续发抖 lh01]"  // 中文等价

// 停止持续发抖
chars: "[sshake lh01]"
chars: "[结束发抖 lh01]"  // 中文等价
```

**注意事项：**
- 多次启动会重启定时器
- 消失立绘时会自动停止
- 批量清除 `[消失 all]` 也会停止

### 11.6 复杂组合示例

```javascript
// 完整组合：位置 + 垂直 + 层级 + 缩放 + 动作
chars: "[左 下 front 10% back lh01]"    // 后退组合
chars: "[右 上 back 10% forward lh01]"  // 前进组合
chars: "[right upm 15% scare lh01]"     // 吓一跳组合
chars: "[左 leftl downm shake lh01]"    // 发抖组合

// 精确坐标 + 动作
chars: "[x:10% y:5% back lh01]"
chars: "[x:-10% y:10% forward lh01]"
chars: "[x:-10% y:10% scare lh01]"

// 中英文混合 + 动作
chars: "[中 back lh01]"        // 中文位置 + 英文动作
chars: "[left 前进 lh01]"      // 英文位置 + 中文动作
chars: "[中 下 shake lh01]"    // 中文位置+垂直 + 英文动作
```

## 12. 最佳实践建议

### 12.1 语言风格选择

- **个人项目**：根据个人喜好选择中文或英文
- **团队协作**：建议统一使用一种语言风格，保持代码一致性
- **混合使用**：在需要时灵活混用，但应避免过度混合导致可读性下降

### 12.2 推荐风格

```javascript
// 风格1：纯中文（适合中文团队）
chars: "[左 下 前 10% lh01]"

// 风格2：纯英文（适合国际化团队）
chars: "[left down front 10% lh01]"

// 风格3：适度混合（根据语义选择）
chars: "[中 front lh01]"  // 位置用中文，层级用英文
```

### 12.3 避免冲突

尽量避免在同一指令中使用同类型的多个关键词，虽然系统会取第一个，但这可能导致混淆：

```javascript
// 不推荐：存在冲突
chars: "[左 right lh01]"  // 虽然有效，但容易引起误解

// 推荐：清晰明确
chars: "[左 lh01]"        // 或者
chars: "[right lh01]"
```

### 12.4 性能优化

- 对于连续的位置变化，如果不需要动画效果，使用 `[瞬]` 或 `[instant]` 可以提升性能
- 避免频繁创建和销毁立绘，尽量复用已有的立绘对象
- 合理的层级管理可以减少渲染开销
- 精确坐标系统适合需要微调的场景，文字指令适合快速布局

### 12.5 精确坐标使用建议

- **微调场景**：当文字指令的位置不够精确时，使用 `x:` 和 `y:` 进行微调
- **动态效果**：结合 JavaScript 动态计算坐标，实现复杂的动画效果
- **响应式设计**：百分比坐标可以自适应不同屏幕尺寸
- **避免过度精确**：一般情况下，文字指令已经足够，只在必要时使用精确坐标

## 13. 常见问题

**Q: 原有的中文剧本需要修改吗？**  
A: 不需要。所有纯中文指令完全兼容，现有剧本无需任何修改。

**Q: center 和 middle 有什么区别？**  
A: 没有区别。`center` 是 `middle` 的别名，两者都映射到相同的居中位置（50%）。

**Q: moment 和 instant 有什么区别？**  
A: 没有区别。两者都是 `瞬` 的英文别名，都会禁用过渡动画。

**Q: hide 和 remove 有什么区别？**  
A: 没有区别。两者都是 `消失` 的英文别名，都会移除指定的立绘。

**Q: 可以混用中英文吗？**  
A: 可以。例如 `[中 front 10% lh01]` 完全合法，系统会正确解析。

**Q: 如果同时写了 [左 右 lh01]，会怎样？**  
A: 系统会取第一个关键词 `左`，结果是 left = 25%，忽略后面的 `右`。

**Q: 推荐使用中文还是英文？**  
A: 根据个人或团队习惯选择。建议在整个项目中保持一致的风格。

**Q: x: 和 y: 的基准点是什么？**  
A: X轴以屏幕中心为0%，Y轴以屏幕底部为0%。

**Q: 精确坐标和文字指令可以同时使用吗？**  
A: 可以，但精确坐标具有更高优先级。例如 `[x:10% 左 lh01]` 会使用 x:10%，忽略“左”。

**Q: 精确坐标支持负值吗？**  
A: 支持。x负值向左，y负值向下。

**Q: 精确坐标会影响缩放吗？**  
A: 不会。坐标和缩放是独立的，缩放不会影响坐标基准点。

**Q: 动作指令可以和瞬移一起使用吗？**  
A: 可以写在一起，但瞬移会被自动忽略。例如 `[瞬 back lh01]` 中，`瞬` 被忽略，后退动画正常播放。

**Q: 如果同时写了多个动作指令会怎样？**  
A: 系统只执行第一个动作指令，忽略后续的。例如 `[后退 吓一跳 lh01]` 只执行后退。

**Q: 持续发抖如何停止？**  
A: 使用 `[sshake lh01]` 或 `[结束发抖 lh01]`。消失立绘时也会自动停止。

**Q: [消失 all] 和 [消失 lh01] 有什么区别？**  
A: `[消失 all]` 清除所有立绘，`[消失 lh01]` 只清除指定立绘。两者都支持英文 `hide` 和 `remove`。

**Q: 批量清除时会停止动画吗？**  
A: 会的。`[消失 all]` 会自动停止所有立绘的动画状态（如持续发抖）。

## 14. 技术说明

### 14.1 解析流程

1. 提取指令中的最后一个部分作为角色ID
2. 将其余部分按空格分割为修饰词数组
3. 遍历修饰词，通过映射表识别关键词类型
4. 对每种类型（水平、垂直、层级、动画），只取第一个匹配的关键词
5. 应用对应的样式属性到立绘元素

### 14.2 兼容性保证

- 所有原有的纯中文指令行为与修改前完全一致
- 现有场景文件无需修改即可正常运行
- 旧的剧本代码不受任何影响
- 新增的英文别名不会干扰现有功能
