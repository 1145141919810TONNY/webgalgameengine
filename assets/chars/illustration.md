# 立绘指令使用指南

本指南详细说明了 Galgame 引擎中立绘（Character）控制的指令格式。通过在 `story` 数组的 `chars` 字段中使用特定的语法，您可以精确控制角色的位置、层级、大小和动画效果。

## 1. 基本语法结构

立绘指令采用方括号包裹的形式：`[修饰词 角色ID]`。

- **修饰词**：用于定义立绘的属性（如位置、缩放等），多个修饰词之间用空格分隔。
- **角色ID**：在配置文件中定义的立绘标识符（如 `lh01`, `lh02`）。
- **多立绘控制**：如果需要同时控制多个立绘，可以使用逗号分隔多个指令，例如：`"[左 lh01],[右 lh02]"`。

**示例：**
```javascript
chars: "[中 lh01]" // 显示 ID 为 lh01 的立绘，位置居中
```

---

## 2. 水平位置控制

通过以下关键词控制立绘在屏幕上的水平位置（`left` 属性）：

| 关键词 | 屏幕百分比 (Left) | 说明 |
| :--- | :--- | :--- |
| `左左` | 15% | 最左侧 |
| `左` | 25% | 偏左侧 |
| `左右` | 35% | 微偏左 |
| `中` | 50% | 屏幕正中央（默认值） |
| `右左` | 65% | 微偏右 |
| `右` | 75% | 偏右侧 |
| `右右` | 85% | 最右侧 |

**代码示例：**
```javascript
// 将 lh01 移动到最左侧
chars: "[左左 lh01]"

// 将 lh01 移动到最右侧
chars: "[右右 lh01]"
```

---

## 3. 垂直位置控制

通过以下关键词控制立绘的垂直偏移（`bottom` 属性）：

| 关键词 | 偏移量 (Bottom) | 说明 |
| :--- | :--- | :--- |
| `下` | -25% | 向下轻微偏移 |
| `中下` | -50% | 向下中等偏移 |
| `下下` | -65% | 向下大幅偏移 |

*注：不指定垂直关键词时，默认为 `0`（底部对齐）。*

**代码示例：**
```javascript
// 将 lh01 向下偏移 50%
chars: "[中 中下 lh01]"
```

---

## 4. 层级控制

通过关键词调整立绘的堆叠顺序（`zIndex`）。基础层级为 10。

| 关键词 | zIndex 值 | 说明 |
| :--- | :--- | :--- |
| `前` | 11 | 顶层（覆盖在其他立绘之上） |
| `后` | 9 | 底层（被其他立绘遮挡） |

**代码示例：**
```javascript
// lh01 在前，lh02 在后
chars: "[中 前 lh01],[中 后 lh02]"
```

---

## 5. 缩放比例

使用带有 `%` 符号的数字来调整立绘的大小。

- **计算规则**：最终缩放比例 = 1 + (输入数值 / 100)。
- **正值**：放大。例如 `10%` 表示放大到 110%。
- **负值**：缩小。例如 `-20%` 表示缩小到 80%。
- **零值**：`0%` 表示保持 100% 原始大小。

**代码示例：**
```javascript
// 放大到 115%
chars: "[中 15% lh01]"

// 缩小到 80%
chars: "[中 -20% lh01]"
```

---

## 6. 动画控制

默认情况下，立绘的位置或大小变化会带有 0.5 秒的平滑过渡动画。

| 关键词 | 效果 |
| :--- | :--- |
| `瞬` | **瞬移**：禁用过渡动画，立绘立即切换到目标状态。 |

**代码示例：**
```javascript
// 瞬间移动到左侧，无动画
chars: "[瞬 左 lh01]"

// 普通移动，有 0.5s 平滑过渡
chars: "[左 lh01]"
```

---

## 7. 组合指令示例

您可以将多个修饰词组合在一个指令中。**修饰词的顺序不影响解析结果**，引擎会自动识别每个关键词。

**解析逻辑：**
1. 提取最后一个部分作为 `角色ID`。
2. 扫描剩余部分，匹配位置、层级、缩放和动画关键词。

**常见组合示例：**

```javascript
// 水平 + 垂直
chars: "[左 下 lh01]" 

// 水平 + 缩放
chars: "[中 10% lh01]"

// 三属性组合：水平 + 垂直 + 缩放
chars: "[左 下 10% lh01]"

// 四属性组合：水平 + 垂直 + 层级 + 缩放
chars: "[右 中下 前 -15% lh01]"

// 完整组合：包含瞬移
chars: "[瞬 中 下下 20% 前 lh01]"
```

---

## 8. 清除立绘

当需要隐藏某个立绘时，使用 `消失` 指令。

**语法：** `[消失 角色ID]`

**代码示例：**
```javascript
// 移除 lh01
chars: "[消失 lh01]"

// 同时移除多个立绘
chars: "[消失 lh01],[消失 lh02]"
```

---

### 总结
通过灵活组合这些修饰词，您可以轻松实现复杂的演出效果，例如“角色从左侧瞬间跳入并放大”或“两个角色在屏幕两侧交替对话”。建议在 `scenes/1.html` 中运行测试场景以直观观察各指令的效果。
