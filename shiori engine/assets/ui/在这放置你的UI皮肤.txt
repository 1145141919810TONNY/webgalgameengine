把系统 UI 图放到本目录。命名 {名字}_{状态}.png（也认 webp / jpg）。

━━━ 第一步：放图 ━━━

状态：_normal 常态；_hover 高亮（可省，回退 normal）；_on 常亮（可省，回退 normal）。

【游戏内部件】（剧本页自动注入，无需逐页配置）
  textbox   对白文本框底图（容器，图 100% 铺满）
            它的 _hover 不是鼠标悬停，由 TEXTBOX_HIGHLIGHT_MODE 驱动（wait/hover/read/off）
  namebox   说话人姓名框（容器）；_on = 该说话人正在发声
  novel     全屏小说模式容器；与对白框换肤互不影响
  options   选项列表整块底图（#options-container）
  choice    选项按钮；_on 同时表示「已选」与「已读」
  btn       顶栏通用功能按钮（AUTO / SKIP 与下面 9 个按钮另有专属位）
  auto      AUTO 自动播放按钮（三态）
  skip1     SKIP 快进按钮·第一组（_on = 快进进行中）
  skip2     SKIP 快进按钮·第二组（已读/未读切换）

【顶栏 HUD 按钮组】默认共用 btn 的图，放了专属图才单独生效
  save（#ui-save）/ dropdown（下拉容器，_on = 展开）/ dd_item（下拉里的 SCENES·MAP·STORY，
  三条文案共用一张图，贴图后仍保留文字，请给无字底图）
  option / system / log / help / back / quit（其余六个按钮）

【浮层与提示】

例：title_start_normal.png + title_start_hover.png → 标题页「开始游戏」换图。
缺图 = 原样 CSS，不报错。

有图时原文字会被隐藏（文字由图自带）。例外：choice / options 即使有图**也保留文字** ——
选项内容来自剧本、图上不可能自带。所以这两个请提供**无字底图**，否则会「图上的字 + DOM 的字」双重叠加。

━━━ 第二步：填尺寸（必须）━━━

引擎运行时**不探测、不解图片、不扫目录**，只读 ui/ui_size.js 里的一张表。
所以每张新图都要手填一次像素尺寸，否则该元素不会生效。

  1) 读出真实像素（工具只跑一次，不进运行时）：
         node tools/measure_ui.js            # 列出全部图与尺寸
         node tools/measure_ui.js --fill     # 输出可直接粘贴的条目
  2) 粘进 ui/ui_size.js：
         title_start_normal: { sizex: 442, sizey: 64 },
         title_bgm_normal:   { sizex: 442, sizey: 64, ext: 'webp' },   // webp/jpg 必须写 ext
  3) 自检：
         node tools/verify_ui_tables.js              # 有错误退出码 1
         node tools/verify_ui_tables.js --release    # 发布门禁：启用条目=0 且本目录无图

⚠ 表里有条目、本目录却没有对应图 → 该元素会隐形（透明底 + 图 404），且不报错。
  这是「手填换性能」唯一的代价，靠上面的自检脚本兜底。

完整槽位表与状态语义见引擎根 assets.md 第 7 节。
