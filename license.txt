零、定义与适用范围

0.1 核心定义
「引擎模板」：指本 GitHub 仓库中发布的 Shiori 引擎核心代码框架，包含引擎源代码、基础结构、开发工具及示例代码。
「衍生作品」：指开发者基于本引擎模板创建的独立视觉小说作品或其他应用程序。衍生作品的版权归属由其创作者自行决定，但须遵守本协议关于引擎署名的要求。
「作者」：指引擎核心代码的版权所有人 bilibili 月が綺麗ですね_。
「引擎资源」：指引擎运行所需的基础技术文件（如 JavaScript 代码、HTML 结构、CSS 样式等），不包含艺术性内容素材。
「素材资源」：指背景图、BGM、人物配音、视频、剧本等非代码内容，此类资源由衍生作品开发者自行提供。
「模板素材」：指本仓库示例或演示中包含的特定素材资源（如背景图、配音、BGM 等），其版权归属于第三方授权方（@友琳_Yurin）。此类素材仅供本地测试和学习参考，严禁在衍生作品中直接使用。
「商用」：指以营利为目的的任何使用、复制、修改、发布或销售行为。

0.2 适用范围界定
本协议仅适用于本 GitHub 仓库中的引擎核心代码及相关开发工具。
本协议不约束用户基于本引擎开发的衍生作品的内容、素材或商业模式，但要求在使用引擎时必须遵守署名规定和素材替换义务。
用户在使用本引擎开发衍生作品时，必须将所有模板素材替换为自有资源或经合法授权的素材，严禁直接使用、分发或外传模板素材。
