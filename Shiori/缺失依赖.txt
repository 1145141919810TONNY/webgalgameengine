一、所需依赖包列表（共8个）
---------------------------------------------------------------------------
以下是编译 ShioriC# 项目所需的所有 NuGet 包：

1. Microsoft.Web.WebView2 (版本: 1.0.2365.46)
   - 用途: WebView2 浏览器控件，用于显示网页内容
   - 下载链接: https://www.nuget.org/api/v2/package/Microsoft.Web.WebView2/1.0.2365.46

2. OpenCvSharp4 (版本: 4.9.0.20240103)
   - 用途: OpenCV 的 C# 封装库，提供图像处理功能
   - 下载链接: https://www.nuget.org/api/v2/package/OpenCvSharp4/4.9.0.20240103

3. OpenCvSharp4.runtime.win (版本: 4.9.0.20240103)
   - 用途: OpenCvSharp4 的 Windows 原生运行时库
   - 下载链接: https://www.nuget.org/api/v2/package/OpenCvSharp4.runtime.win/4.9.0.20240103

4. Microsoft.NETCore.App.Runtime.win-x64 (版本: 8.0.27)
   - 用途: .NET Core 运行时，提供基础运行环境
   - 下载链接: https://www.nuget.org/api/v2/package/Microsoft.NETCore.App.Runtime.win-x64/8.0.27

5. Microsoft.WindowsDesktop.App.Runtime.win-x64 (版本: 8.0.27)
   - 用途: Windows Desktop 运行时，支持 WPF 等桌面应用
   - 下载链接: https://www.nuget.org/api/v2/package/Microsoft.WindowsDesktop.App.Runtime.win-x64/8.0.27

6. Microsoft.AspNetCore.App.Runtime.win-x64 (版本: 8.0.27)
   - 用途: ASP.NET Core 运行时，支持 WebView2 等功能
   - 下载链接: https://www.nuget.org/api/v2/package/Microsoft.AspNetCore.App.Runtime.win-x64/8.0.27

7. System.Runtime.CompilerServices.Unsafe (版本: 6.0.0)
   - 用途: 提供 Unsafe 类的运行时支持，OpenCvSharp4 的传递依赖
   - 下载链接: https://www.nuget.org/api/v2/package/System.Runtime.CompilerServices.Unsafe/6.0.0

8. System.Memory (版本: 4.5.5)
   - 用途: 提供 Memory<T> / Span<T> 等类型支持，OpenCvSharp4 的传递依赖
   - 下载链接: https://www.nuget.org/api/v2/package/System.Memory/4.5.5

二、文件放置方法
---------------------------------------------------------------------------
1. 使用浏览器访问上述链接，下载所有 .nupkg 文件
2. 将下载的文件放入以下目录（本文件同级的 nupkg 文件夹）：
   Shiori\nupkg\
   
3. 放置后目录结构应如下：
   Shiori/
   ├── nupkg/
   │   ├── microsoft.web.webview2.1.0.2365.46.nupkg
   │   ├── opencvsharp4.4.9.0.20240103.nupkg
   │   ├── opencvsharp4.runtime.win.4.9.0.20240103.nupkg
   │   ├── microsoft.netcore.app.runtime.win-x64.8.0.27.nupkg
   │   ├── microsoft.windowsdesktop.app.runtime.win-x64.8.0.27.nupkg
   │   ├── microsoft.aspnetcore.app.runtime.win-x64.8.0.27.nupkg
   │   ├── system.runtime.compilerservices.unsafe.6.0.0.nupkg
   │   └── system.memory.4.5.5.nupkg

三、编译步骤
---------------------------------------------------------------------------
1. 确保所有 .nupkg 文件已正确放入 nupkg 目录
2. 双击运行 build_csharp.bat
3. 脚本会自动检测本地包并使用本地源编译
4. 编译成功后，输出文件在 dist/ 目录下

四、常见问题及解决方法
---------------------------------------------------------------------------
Q1: 下载链接打不开？
A: 请确保网络连接正常，或尝试使用其他浏览器下载

Q2: 提示"找不到版本为 (= 8.0.27) 的包"？
A: 请确认下载的包版本正确（必须是 8.0.27，不是其他版本）

Q3: 编译时仍然提示网络错误？
A: 请检查 nupkg 目录中是否缺少某个包，或包文件名是否正确

Q4: 是否需要安装 .NET SDK？
A: 是的，需要安装 .NET 8.0 SDK 才能编译
   下载地址: https://dotnet.microsoft.com/download/dotnet/8.0
